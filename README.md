Privacy Policy for Invoice Pro+ (Git Repository)

Effective Date: 02-28-2026
Last Updated: 02-28-2026

This Privacy Policy applies to the Invoice Pro+ source code repository hosted on GitHub and managed using Git.

This policy explains how information may be collected and used in connection with contributions, issue submissions, and repository interactions.

⸻

1. Information Collected

When you interact with this repository (for example by submitting issues, pull requests, or comments), the following information may be visible:
	•	GitHub username
	•	Profile information you choose to make public
	•	Email address (if publicly available in commits)
	•	Commit history and contribution data
	•	Any information you voluntarily include in issues or pull requests

We do not directly collect personal data outside of what is publicly available through GitHub.

⸻

2. How Information Is Used

Information may be used to:
	•	Review and manage pull requests
	•	Respond to bug reports and feature requests
	•	Maintain project integrity
	•	Improve the Invoice Pro+ application
	•	Credit contributors

⸻

3. Third-Party Platform

This repository is hosted on GitHub. GitHub may collect additional data according to its own Privacy Policy. We do not control GitHub’s data practices.

You are encouraged to review GitHub’s Privacy Policy directly on their website.

⸻

4. Data Storage

All repository data is stored on GitHub’s servers. We do not maintain separate databases of contributor information beyond what is stored within the repository platform.

⸻

5. Public Nature of Contributions

Please note:
	•	All issues, pull requests, and commits may be publicly visible.
	•	Do not submit sensitive personal information.
	•	Any information submitted may remain in the repository history.

⸻

6. Data Removal Requests

If you believe personal information has been shared unintentionally, please contact:

Admin@trumasolutions.com

We will review requests and take appropriate action where possible (note: Git commit history may not always be fully erasable).

⸻

7. Changes to This Policy

We may update this Privacy Policy at any time. Updates will be reflected in the repository with a revised date.
